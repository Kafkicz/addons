# Jakub's Home Assistant Add-on Repository

Tento repozitář obsahuje doplňky pro Home Assistant.

## Seznam doplňků

### [Mastodon Server](mastodon_server/)
Plnohodnotná instance Mastodon běžící jako Home Assistant Add-on.

## Jak používat
1. Otevřete svůj Home Assistant.
2. Přejděte do **Settings** -> **Add-ons** -> **Add-on Store**.
3. Klikněte na tři tečky vpravo nahoře a vyberte **Repositories**.
4. Přidejte URL tohoto repozitáře.
5. Nainstalujte **Mastodon Server**.
